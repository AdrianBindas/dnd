## Potion research
1. **Research phase**
	- downtime study - Wisdom check DC 15. Grants 1 RP
	- dissection in the field - Medicine check DC 17. Grants 2 RPs.
	- trials - Wisdom check DC 20. Try it out to gain 2 RPs.

| Rarity    | RP Required |
| --------- | ----------- |
| Common    | 2           |
| Uncommon  | 4           |
| Rare      | 8           |
| Very Rare | 12          |
| Legendary | 16          |
2. **Experimental phase**:
Roll d20 + Wisdom + proficiency to brew experimental substance against d20 + rarity modifier. Craft 3 substances to master the brewing process. Roll Medicine check to assess the success of the resulting substance.

| Rarity    | Mod |
| --------- | --- |
| Common    | +0  |
| Uncommon  | +5  |
| Rare      | +10 |
| Very Rare | +15 |
| Legendary | +20 |

| Roll Result                   | Outcome                                |
| ----------------------------- | -------------------------------------- |
| **Critical Success (Nat 20)** | 2 substances created successfully      |
| **Success (DC met)**          | substance created successfully         |
| **Partial Success (DC – 5)**  | substance works but with a side effect |
| **Failure (Below DC)**        | substance fails, only side effect      |
| **Critical Failure (Nat 1)**  | substance fails, only 2 side effects   |
3. Master phase:
Roll d20 + Wisdom (Alchemist’s Tools or Herbalism Kit proficiency) to brew substance you already mastered. On failure (DC 15) the potion has side effect.
